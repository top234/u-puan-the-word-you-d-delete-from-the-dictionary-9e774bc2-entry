The word I would delete from the dictionary is **"lisp"**. It is the name of a speech impediment that people who have it cannot even pronounce — the word itself is the joke, and it lands the moment you read it, with no explanation needed. Deleting it would leave the language without a word for the very thing it describes, which is exactly what makes the pick fresh and instantly understood.

## How it works

`main.ts` is a dependency-free Node program. It writes the single word `lisp` — exactly four bytes, with no trailing newline — to `entry.txt` inside the directory given by the `OUTPUT_DIR` environment variable (defaulting to `/output`), creating the directory first if needed.
